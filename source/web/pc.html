Tips for maximum speed
  • Connect the iPhone to the 5 GHz Wi-Fi, not 2.4 GHz.
  • Plug this PC into the router with an Ethernet cable if you can.
  • No router? Turn on Windows Mobile Hotspot (Settings → Network → Mobile hotspot), join it on the iPhone, then pick 192.168.137.1 above.
  • Send many files at once — PhoneDrop uploads 3 in parallel.
  • iPhone can't connect? Windows Firewall may be blocking it: allow PhoneDrop on Private networks, and set your Wi-Fi to Private.
